# Procurement — buying equipment, consumables, and contracts

When buying a new piece of equipment, a cable, or anything else for a CTP, use this workflow. Internal forms and budget templates live in the CTP Drive — only the public form URLs are listed here.

## 1 — CTP Requisition Request

Fill the **CTP Requisition Form** (Google Form, requires NYU login):
<https://docs.google.com/forms/d/e/1FAIpQLSewUcPh-me_TIw0wTxYVOP-v93ibHpKusiT3CpmfuWLgafvkw/viewform>

## 2 — OTPS budget

Charges should map to the platform's OTPS line in the annual CTP budget (maintained internally by the Admin Coordinator).

## 3 — Competitive Bid Exception (CBE), if applicable

If a CBE is required (sole-source vendor, urgency, etc.):
<https://services.nyuad.nyu.edu/forms/competitive-bid-exception>

## 4 — Equipment lifecycle / capital request

Multi-year capital planning uses the internal **CTP Lifecycle Equipment** template and the **Funding Request Form**. Ask the Admin Coordinator for the current templates.

Common scientific-instrument distributor:
<https://qd-europe.com/> (Quantum Design Europe)

## 5 — Chartfield

Per-platform chartfield codes (fund / dept / program / project) are managed internally by the Admin Coordinator. They are not stored in this public repo — ask the Admin Coordinator for the correct chartstring for your platform.
